# RESOURCES.md Format

`RESOURCES.md` is the curated set of trusted sources for the topic. Draw explanatory knowledge from it rather than unsupported guesses. Wisdom comes from its listed communities.

## Structure

```md
# {Topic} Resources

## Knowledge

- [Book: _The Science and Practice of Strength Training_ — Zatsiorsky & Kraemer](https://example.com)
  Foundational text on programming and adaptation. Use for periodisation, recovery, and intensity zones.
- [Article: "How Much Should I Train?" — Greg Nuckols (Stronger By Science)](https://example.com)
  Evidence-based review of volume landmarks. Use for weekly set targets per muscle group.

## Wisdom (Communities)

- [r/weightroom](https://reddit.com/r/weightroom)
  High-signal subreddit, moderated against bro-science. Use for programme critique and plateau troubleshooting.
- Local: Tuesday strength class at {gym name}
  Use for real-time coaching feedback on lifts.
```

## Rules

- Use only high-trust sources: primary sources, recognized experts, peer-reviewed work, and strongly moderated communities.
- Annotate every entry with what it covers and when to use it.
- Group sources under Knowledge and Wisdom. A source may belong to only one group.
- If the mission needs a resource that does not exist, add a `## Gaps` section naming the missing knowledge.
- Remove resources that prove wrong, shallow, or off-mission; prefer five sharp sources to thirty mediocre ones.
- Record a user's preference not to join communities so future lessons respect it.
